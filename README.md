# Двухслойная когнитивная архитектура

Публичный проектный эскиз архитектуры взаимодействия человека и ИИ: событийный HUD для оператора, headless-контур исполнения, верифицируемый компилятор семантических контрактов и персональный когнитивный слой с управляемой консолидацией памяти.

**Статус:** открытый черновик для обсуждения; это архитектурная гипотеза, а не описание готовой реализации.
