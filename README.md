# Dual-Layer Cognitive Architecture

[Russian version / Русская версия](README.ru.md)

**An open architectural project for the next generation of human-AI systems.**

This public project explores a two-layer architecture for human-AI interaction: an event-driven operator HUD, a headless deterministic execution layer, a verifiable semantic contract compiler, and a personal cognitive layer with controlled memory consolidation.

> **Status:** An open architectural draft for discussion. This repository describes a research hypothesis and specification, not a production-ready implementation.

## Architecture overview

The proposed system separates strategic human control from machine execution:

- **Strategic layer:** A human operator defines objectives, reviews invariants, and authorizes critical transitions through a quiet, event-driven HUD.
- **Execution layer:** AI components and deterministic algorithms operate through a headless machine interface with no decorative graphical translation layer.
- **Semantic layer:** Natural-language intent is compiled into constrained, verifiable intermediate-representation (IR) contracts.
- **Cognitive memory layer:** Short-term project context is distilled into durable, versioned invariants and adapter weights.

The core research areas include:

- Human-AI interaction and **Zero UI** interface design
- Event-driven operator dashboards and **HUD avionics**
- Deterministic agent orchestration
- Semantic contract compilation and static AST verification
- AOT/JIT contract verification
- Personal cognitive memory architectures
- Long-term memory consolidation and LoRA-based adaptation

## Key concepts

### Dual-layer human-machine interface

The operator and execution system use separate interaction environments. Routine work remains silent, while the operator sees only state deltas and approval requests at critical transition points.

### Verifiable semantic compiler

Large cognitive models are restricted to semantic translation at system boundaries. Human intent is projected into a constrained intermediate representation, then checked for syntax, types, side effects, and sandbox requirements before execution.

### Personal cognitive memory

The proposed memory metabolism separates raw session context, crystallized verified invariants, and adapter weights. Nightly adaptation is limited to cleaned, approved "golden nodes," reducing the risk of contamination from raw conversational noise.

### Deterministic execution

Smart deterministic algorithms and narrow specialized models handle routine execution, while probabilistic AI is not used as an uncontrolled universal orchestrator.
